## 4. 데이터 출처 카드 (초안, 호출해서 확인한 뒤 완성)
| 데이터 | 용도 | 확인 상태 |
|---|---|---|
| CISA KEV (github.com/cisagov/kev-data) | 기준 데이터: 실제 악용 취약점, 조치 기한 | CC0, JSON·CSV·스키마 파일 존재 확인. **필드명은 스키마로 확인 필요** |
| NVD CVE API 2.0 | 보강: 영향 제품·심각도 | 키 발급 필요, 호출 한도는 비공식 자료(키 없이 30초 5회) — **확인 필요** |
| EPSS (FIRST) | 보강: 악용 가능성 점수 | 키 불필요는 2차 자료 기준 — **확인 필요** |

### KEV 직접 호출 결과 (2026-10-22 확인)
- 내려받기 성공(JSON 약 1.8MB). `catalogVersion` 2026.10.21, 항목 1,754개, 가장 최근 `dateAdded` 2026-10-20.
- 필드: `cveID`, `vendorProject`, `product`, `vulnerabilityName`, `dateAdded`, `shortDescription`, `requiredAction`, `dueDate`, `knownRansomwareCampaignUse`(Known/Unknown), `forensicTriage`, `notes`, `cwes`(배열).
- 벤더 상위: Microsoft 390, Cisco 101, Apple 95, Adobe 82, Google 75, Oracle 46, Apache 41, Ivanti 36, Fortinet 32.
- **산업 제어 벤더는 매우 적다**: Siemens 2, Rockwell 1, Schneider Electric 1. → 가상 자산은 IT·네트워크 장비(Cisco·Fortinet·Ivanti·Palo Alto 등)와 Windows 기반 설비 PC·원격접속 장비 중심으로 만든다.
- **`dueDate`가 이미 지난 항목이 1,754개 중 1,748개**: "기한 임박"보다 "기한 초과 일수"와 "최근 등록"이 우선순위 기준이 된다.
- 랜섬웨어 악용 Known 361개, Unknown 1,393개.

한계(발표에서 밝힌다): KEV는 미국 기준 목록이고, 자산 ↔ KEV 매칭은 제품명 문자열 비교라 정확도가 완벽하지 않다.
