# Intent — 가상 공장 데이터셋 제작 과정

가상 공장 데이터셋(`dataset-v2`)을 만든 과정을 단계별로 기록한다. 최신이 위다. 각 단계는 문제 → 기대 결과 → 영향 범위 → 제약 → 열린 질문 → 결과 순서이며, 결과에는 실제로 확인한 것과 확인하지 못한 것을 구분해 적는다. 숫자는 `07_데이터셋_v2_변경내역.md`의 자동 표가 정본이고, 여기에는 과정과 판단을 적는다.

공통 전제: 회사·공장·자산은 가상이다. 제품·버전 번호는 실제 공개 번호를 가정해 배정한 값이다. 원본(`docs/datasets/manufacturing-mes-20261022/`)은 건드리지 않고 파생 파일을 만든다. DB는 건드리지 않는다. 생성은 시드(20261024)로 재현된다.

## 2026-10-24 · 11단계 — 공정(라인) 유형별 구조 재구성

### 문제
- 12·16·24개 라인이 모두 같은 구성(자산 24~26개, 공정 목록 한 가지)이다. 제품이 달라도 같고, 공정과 설비가 연결되지 않는다(소재 투입·디버링·포장에는 설비가 없음).
- CNC마다 Windows 조작 PC가 하나씩 있고, 중요도는 거의 전부 high, OT 제약은 전부 같다. 통신은 자산당 1건도 안 된다.

### 기대 결과
- 라인 유형(가공 / 세척·검사 / 조립·포장)마다 설비 종류와 수가 다르다. 소재 투입·디버링·포장도 PLC를 가진다.
- CNC는 내장 패널을 쓰고 Windows HMI는 라인당 1~2대다. 제조사 번들 OS는 일반 패치 대상과 구분해 표시한다.
- 중요도는 병목 공정과 이중화 여부로, 작업 제약은 협력사 관리·무정지 여부로 나뉜다.
- OT는 도입 시점 빌드를 유지하고 일부만 점검 때 갱신한다. 사무 PC는 월 패치로 최근 빌드 중심이다.

### 영향 범위
| 구분 | 내용 |
|---|---|
| 사용자 | 이 데이터로 화면·수집기·매칭을 시험하는 팀원 |
| 시스템·파일 | `dataset-v2/generate_v2.py`, `v2_rules.py`, 출력 JSON·엑셀. 자산·설비·라인·대장·설치 목록·통신·스위치 포트 결합·작업지시 관측의 연결을 함께 고쳐야 한다 |
| 영향 없음 | 원본 JSON, DB, 앱 코드, AI4I 원본 값 |

### 제약
- 사용자가 정한 방향: 라인 유형은 3유형(제가 가정, "가정"으로 표시), CNC는 내장 패널 + 라인당 공용 HMI 1~2대, 중요도는 병목 공정 + 이중화 여부, 패치 정책은 OT 도입 시점 빌드 유지·사무 PC 월 패치.
- AI4I 관측값(공정 가공 데이터)은 원본 값을 그대로 둔다. 가공 라인 CNC에만 붙인다.
- 새 제품의 모델·버전을 임의로 만들지 않는다(미상으로 둔다).

### 결과
- **구현:** 라인 유형 3종(가공 / 세척·검사 / 조립·포장)과 유형별 설비 구성, 공정·병목·이중화·관리 주체 표시, 병목·이중화 기반 중요도와 제조사·단일 지점 기반 작업 제약, 라인당 공용 HMI, 라인 안 통신(VMA 102 → 260건), 2021~2024년 공식 빌드 후보와 OT·사무 패치 정책, 담당 5종, 불규칙한 시리얼·IP.
- **검증:** 세 회사 모두 생성기 검사 통과(새 검사: 라인 유형별 CNC 수, 라인당 CNC 제조사 2종 이하, 대장과 정답 일치). 스위치 포트 최대 12개(한도 14), 시리얼·IP 중복 없음, AI4I 원본 값 보존, 관측은 CNC 설비에만 연결. 서로 다른 라인 구성은 VMA 10·VMB 14·VMC 19가지.

- **조사:** Microsoft 공식 빌드 이력표(2021-11~2024-07, 빌드·KB·날짜)를 원문에서 파싱했다.

## 2026-10-24 · 9단계 — 공정(라인)별 제조사 통일과 서버 계층(수집·메인) 설치 목록

- **구현:** 라인 프로필(제조사·도입 시기 웨이브), 서버 OS(Windows Server 2016·2019·2022, RHEL 8)와 응용(KEPServerEX, Ignition, WinCC)을 설치 목록에 분리, MES DB 주 제품 혼합(SQL Server 2019·2017, Oracle 19c). 오류가 표시된 필드를 가진 자산도 바꾸고 그 오류 표시(별칭·약어)는 새 값에 맞게 다시 만들거나 없앴다. 제품이 섞인 라인이 VMA 1·VMB 1·VMC 2개로 줄었다.
