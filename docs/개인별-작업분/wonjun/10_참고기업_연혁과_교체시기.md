# 참고 기업 연혁과 장비 교체 시기 판단

조사일 2026-10-25. 데이터셋의 가상 회사 3곳(VMA·VMB·VMC)은 자동차 동력전달 부품 업종의 실제 기업 3곳을 **업종 참고용**으로만 연결했다(`company_references.json`의 안내: 설비·인원·공장 수·MES·벤더·버전·IP·오류·취약점·패치 이력은 실제 기업 정보가 아니다). 이 문서는 그 참고 기업의 **공개 연혁**을 가상 공장의 라인 개설 시점을 정하는 근거로 쓰고, 그 위에 장비 교체 시기를 **판단(가정)** 한 기록이다. 가상 공장의 설비가 실제 기업의 설비라는 뜻이 아니다.

## 3. 장비 교체 시기 판단 (가정)
사용자 판단: 장비는 보통 **10년 주기**로 바뀌고, **안 바뀌는 경우도 많다**. 이를 아래 규칙으로 옮겼다. 확률과 주기는 모두 가정이다.

| 종류 | 교체 주기 | 주기가 지났을 때 교체할 확률 |
|---|---|---|
| CNC·PLC·로봇 컨트롤러 | 10년 | 35% |
| 인버터 | 10년 | 40% |
| 산업용 스위치 | 10년 | 45% |
| HMI·비전 PC | 7년 | 60% |
| 엣지 수집 PC·안돈·바코드 리더 | 6~8년 | 40~60% |

- 라인 개설 연도에 장비를 설치한 것으로 보고, 2026년 기준 운영 연수가 주기 이상이면 확률로 교체한다. 교체하면 주기(±1~2년)만큼 뒤 연도에 새 장비가 설치되고, 여전히 주기 이상이면 같은 확률로 다시 판정한다. **교체하지 않은 장비는 원래 도입 연도의 구형을 그대로 쓴다.**
- 구형 제품 규칙: 2008년 전에 도입한 제어기는 제조사만 라인의 구형 프로필을 따르고 모델은 **"모델 미상"** 으로 적었다(당시 제품명을 검증하지 못함). 2008~2015년 도입분은 구형 제품명(예: FANUC 0i-MD, MELSEC-Q, MASTER-K, S7-300, FR-A700, Catalyst 2960, R-30iA, DX100)이며 **이름은 일반 지식 기반이고 이 자료에서 검증하지 않았다.** 이들은 버전·공지 판정이 없다. 교체된 장비는 같은 제조사의 후속 제품(예: 0i-MD → 0i-MF Plus)으로 바꿨다.
- PC의 OS는 도입 연도로 정했다: 2000년 이전 구형(버전 미상), 2001~2010 Windows XP SP3, 2011~2017 Windows Embedded Standard 7 SP1, 2018 이후 Windows 10·11. 지원 종료일은 Microsoft 수명주기 페이지 원문을 확인했다: Windows XP 2014-04-08, WES7 2020-10-13(계약이 있는 경우 ESU 3년차 2023-10-10까지). 지원이 끝난 OS가 현장에 남아 있는 것은 "안 바뀌는 경우"에 해당한다.
- 2024년 이후 도입 설비에는 Siemens 840D sl을 넣지 않았다(2024-10 단종, 유통사 글 근거).
- 기반 서버·네트워크는 2016년 이후 교체된 것으로 보고 연도를 뽑았다. OS는 출시 연도 이후로 맞췄다.

## 4. MES 도입 시기 판단 (가정)
사용자 판단: MES를 도입한 지 얼마 안 된 회사도 많다. 그래서 MES·수집 계층 장비(MES 앱·DB 서버, OPC 수집 서버, 이력 서버, 엣지 수집 PC, 안돈, 바코드 리더)는 라인 개설 연도가 아니라 **MES 도입 연도 이후**에 설치된 것으로 두고, MES 이전에 개설된 라인에는 도입 때 뒤늦게 붙인 것으로 표시했다(`mesRetrofitYear`).

| 가상 회사 | MES 도입 연도(가정) | 근거 |
|---|---|---|
| VMA | 2020 (재구축) | 참고 기업의 공개 연혁에 MES 구축완료(2005)가 있어, 2005년 시스템을 최근 다시 구축한 것으로 가정 |
| VMB | 2021 | 공개 연혁에서 확인 못 함. 최근 도입 가정 |
| VMC | 2022 | 공개 연혁에서 확인 못 함. 여러 공장 통합을 최근으로 가정 |

엣지 수집 PC의 Ubuntu 22.04는 2022년 출시이므로 설치 연도를 2022년 이후로 맞췄다.

## 6. 한계와 확인 필요
- 연도·교체 주기·교체 확률·MES 도입 연도는 **모두 가정**이다. 참고 기업의 실제 설비 도입 연도와 MES 시기는 공개 자료에서 확인하지 못했다(설비 투자액도 확인 못 함).
- 디아이씨 연혁은 snippet 위주이고 공식 연혁 페이지가 이미지다. 서진은 연혁을 직접 읽었으나 설비 투자는 없다. 대동기어의 설비 대수 요약값은 재확인하지 않았다.
- 구형 제품 이름은 일반 지식이다. 2008년 이전은 모델을 일부러 적지 않았다. 그 사이 시기의 제품 출시 연도와 단종 시기는 검증하지 않았다.
- 한 공장의 라인 수(12~16개)와 연도 배치는 연혁에서 직접 나온 값이 아니라 사건 근처로 맞춘 것이다.
- 현장 경험에 비추어 주기·확률이 다르면 `v2_rules.py`의 `REPLACE_CYCLE`, `LINE_YEARS`, `MES_YEAR`만 고쳐 다시 만들면 된다.
