# 자산과 취약점 매칭은 시스템이 후보를 찾고 사람이 확인한다

KEV에는 버전 필드가 없고 벤더·제품 이름이 자산 목록의 표기와 달라 자동 매칭은 틀릴 수 있다. 문자열 비교로 **매칭 후보**만 만들고, 담당자가 **확인**(해당함/해당 없음)한 짝만 **위험 항목**으로 삼는다. 완전 자동 판정은 오탐·미탐이 우선순위 전체를 흔들어서 선택하지 않았다.

## Considered Options
- 완전 자동 매칭: 빠르지만 오탐을 사람이 알아채기 어렵다.
- 사람 확인(채택): 한 단계가 늘지만 근거가 남고 감사 증적이 된다.

## Consequences
- 확인 안 된 후보가 쌓이면 목록이 길어진다 → 후보는 우선순위 점수 순으로 상위만 기본 표시.
- 발표에서 "매칭 정확도의 한계와 그 보완 방법"으로 설명한다.
