# 가상 공장 데이터셋 v2 — 변경 내역

원본(`docs/datasets/manufacturing-mes-20261022/`)은 그대로 두고, 같은 폴더의 생성기(`dataset-v2/generate_v2.py`)가 **파생 파일**을 만든다. 모든 변형 값은 시험용 가정이며 실제 회사·장비의 사실이 아니다.

## 만드는 법
```
cd dataset-v2
python generate_v2.py <원본 폴더> out research_versions.json
```
같은 시드(20261024)면 같은 결과가 나온다. 결과 파일(약 9.6MB)은 저장소에 넣지 않고 생성기와 조사값만 둔다.

## 조사한 패치 버전 (`research_versions.json`)
- 공식 확인: Windows 10/11·Server 2019/2022 월간 빌드, SQL Server 2019 CU, Ubuntu 22.04 포인트 릴리스, ESXi 7.0 빌드, Veeam 12 빌드, Cisco 권장 릴리스.
- 2차 자료(공식 확인 못 함): ESXi 6.7 지원 종료, FortiOS 7.2 종료일, PAN-OS 10.2 핫픽스, Moxa 펌웨어, Siemens S7-1500·FANUC·Mitsubishi 펌웨어 번호.
- **확인 필요(값 비워 둠):** FANUC 0i-MF Plus, FR-A800, KEYENCE SR-2000, Veeam 12 지원 종료일, Cisco·Moxa 단종 공지.
- **재대조(2026-10-24):** 별도 점검에서 Windows·Server 빌드와 KB, ESXi 7.0·6.7 빌드, Veeam 12, Cisco, PAN-OS, FortiOS 빌드, FANUC V9.xx, Mitsubishi 펌웨어 번호가 원문과 일치했다. 수정한 것: Cisco 17.18.4와 Veeam 12.3.2 P4 추가, Windows 11 23H2 종료일을 Enterprise 기준으로 확정, ESXi 패치 이름은 확인 못 해 비움.
- 수명주기 날짜는 태평양 시간 기준이며 수명주기 표에서 하루 뒤로 보이는 경우가 있다(SQL 2019, Server 등).
- **아직 재대조하지 못한 것:** Moxa EDS-516A, Siemens S7-1500·SINUMERIK, Windows Embedded Standard 7, PAN-OS 핫픽스 h1·h8.
- 값은 실제 장비의 설치 값이 아니라 가상 자산에 나눠 준 대략적 수준이다.

## 하지 않은 것
- CNC–HMI 1:1 구조 분리, 절삭유·측정기·무선 AP 등 자산 종류 추가.
- 네트워크 오류(IP 충돌 등) 삽입: 대장 오염에만 반영.
- 원본 파일 수정, 펌웨어 값 임의 생성.
