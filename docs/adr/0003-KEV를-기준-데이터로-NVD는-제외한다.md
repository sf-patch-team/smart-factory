# KEV를 기준 데이터로 쓰고 NVD 연동은 1차에서 제외한다

KEV는 키 없이 파일로 받을 수 있고 항목마다 조치 기한과 랜섬웨어 악용 여부가 있어 우선순위 기준으로 충분하다. NVD는 키 발급과 호출 한도(비공식 자료 기준 키 없이 30초 5회) 확인이 필요해 마감(2026-10-27)에 위험이 크다. EPSS는 시간이 남으면 보강으로 추가한다. 가져온 데이터는 DB에 저장하고 화면에는 항상 **받은 시각**을 보여 준다.

## Consequences
- 영향 제품·심각도 점수는 이번 범위에 없다.
- KEV의 `dueDate`가 대부분(1,754개 중 1,748개) 이미 지나 있어 점수는 "기한 초과 일수" 중심이다(2026-10-22 직접 확인).
