# IA — 정보구조와 화면목록

상태: 검토용 초안 · 첫 버전과 후속을 구분해 표시

## 구조 요약

- **메뉴:** 비로그인은 로그인(`/login`)·가입(`/signup`), 담당자는 자산·위험·요청, 관리자는 승인·전체 자산·이력·데이터 메뉴를 쓴다.
- **화면 ID 읽는 법:** 영역 약어(AU 인증, DB 현황, AS 자산, RK 위험, RQ 요청, AD 관리) + 번호 + 형태(P 페이지, M 모달, T 탭).
- **첫 버전과 후속의 경계:** 현황 대시보드(`/`, `/admin`)와 통계(`/admin/stats`)는 후속이다. 첫 버전의 `/`는 요청 목록으로, `/admin`은 승인 목록으로 안내한다. 자산 상세 편집 이력 화면, 위험 점수·우선순위, EPSS, 묶음 확인도 후속이다.
- **알림:** 알림함·읽음 상태·자동 메일/푸시는 후속이다. 첫 버전은 재검토일·기한 도래 문구와 목록 필터만 제공한다.
- **주의:** 경로 파일이 있다고 기능이 완성된 것은 아니다. 별도 표시가 없는 화면은 첫 버전의 최소 기능이다.

## 화면 구조와 목록

기존 Next.js 경로를 유지하는 설계안이다. 경로 파일의 존재는 실제 기능 완성을 뜻하지 않는다. 화면 ID는 영역 약어-번호-형태(P 페이지·M 모달·T 탭) 표기를 쓴다.

| 화면 ID | 화면 / 경로 | 형태·주요 정보 | 접근 범위 |
|---|---|---|---|
| AU-01-P / AU-02-P | 로그인 `/login` / 가입 `/signup` | 페이지·인증·오류 복구 | 비로그인. 가입자는 member만 부여 |
| DB-01-P | 내 현황 `/` | **후속 FR-10**: 진행 요청·보류 재검토 집계 카드 | 로그인, 자기 범위. 첫 버전 `/`는 요청 목록으로 안내 |
| AS-01-P / AS-02-M | 자산 `/assets` | 첫 버전: 페이지+등록·수정 모달(요청이 생기기 전까지 식별 정보 수정, 수정마다 이력 한 줄)·제품·버전·확인 상태. 상세 편집 이력 화면은 후속 FR-04 | 담당자는 자기 자산 |
| AS-03-P | 자산 상세 `/assets/[id]` | 첫 버전: 식별 정보·관련 요청. 자산 변경 전후 이력·합성 과거 이력은 후속 FR-04·26 | 소유자 또는 관리자 |
| RK-01-P / RK-02-T | 위험 `/risks` | 첫 버전: 페이지+후보 탭·확인 결과·갱신 상태 | 로그인, 권한 있는 자산 |
| RK-03-T | 위험 탭 `/risks` | **후속 FR-09**: 점수·우선순위 정보. 기존 ID 유지 | 로그인, 권한 있는 자산 |
| RK-04-P / RK-05-M | 위험 상세 `/risks/[id]` | 페이지+해당 여부 확인 모달·원문 근거 | 권한 있는 자산 |
| RQ-01-P / RQ-02-P | 요청 `/requests` / 신청 `/requests/new` | 페이지·목록/체크리스트·입력 오류 | 담당자, 자기 범위 |
| RQ-03-P / RQ-04-M / RQ-05-M | 요청 상세 `/requests/[id]` | 페이지+처리/보류 모달·근거·이력 | 요청 담당자 또는 관리자 |
| AD-01-P | 관리 현황 `/admin` | **후속 FR-17**: 승인 대기·보류 집계 카드 | 관리자. 첫 버전 `/admin`은 승인 목록으로 안내 |
| AD-03-P | 전체 자산 `/admin/assets` | 첫 버전: 허용 범위 전체 자산 조회 | 관리자 |
| AD-02-P / AD-07-P | 승인 목록 `/admin/requests` / 상세 `/admin/requests/[id]` | 페이지·승인/반려·사유·근거 | 관리자 |
| AD-04-P / AD-05-P | 전체 이력 `/admin/history` / 데이터 `/admin/data` | 페이지·필터/마지막 성공 갱신·실패 상태 | 관리자 |
| AD-06-P | 통계 `/admin/stats` | 페이지·후속 선택 기능 | 관리자, 핵심 흐름 밖 |

첫 버전 메뉴: 담당자는 **자산·위험·요청**, 관리자는 **승인·전체 자산·이력·데이터**. 내 현황·관리 현황 대시보드와 통계 메뉴는 후속이다. 목록→상세/입력의 2단계를 기본으로 하고 처리는 상세의 모달로 연다. 목록 정보 순서는 대상 자산→진행 상태/다음 행동→마지막 갱신·근거다. 이력 증가에는 기간·상태 필터와 페이지 구분을 사용한다. 상세에서 관련 자산·이전 요청·관리자 승인으로 이동하는 맥락 링크를 둔다.

별도 표시가 없는 화면은 첫 버전의 최소 기능이다. 위험 상세의 점수·EPSS·묶음 확인은 후속이다. **첫 버전은 재검토일·기한 도래 문구와 목록 필터만 제공**한다. 알림함·읽음 상태·자동 메일/푸시·예약 알림 작업은 후속이며 별도 알림 화면 ID는 두지 않는다.
